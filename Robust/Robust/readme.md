## Robustness Handling in File Download Console App (.NET 9)

### چالش
یک اپلیکیشن کنسولی بنویسید که یک فایل را از اینترنت دانلود کند و در برابر قطع اینترنت یا توقف ناگهانی سیستم مقاوم باشد. برنامه باید بتواند دانلود را از همان نقطه‌ای که قطع شده ادامه دهد و خطاهای شبکه و IO را به صورت مناسب مدیریت کند. استفاده از حافظه موقت یا کش مجاز نیست و وضعیت باید روی دیسک ذخیره شود.

### راهنمای شروع
- پروژه را با .NET 9 ایجاد کنید.
- از HttpClient برای دانلود فایل استفاده کنید.
- وضعیت دانلود باید روی دیسک ذخیره شود (مثلاً با استفاده از فایل .part).
- در صورت بروز خطا، پیام مناسب به کاربر نمایش داده شود و برنامه به صورت امن متوقف شود.
- پس از راه‌اندازی مجدد، دانلود باید از نقطه قبلی ادامه یابد.

### مستندات اولیه
- [HttpClient](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient)
- [FileStream](https://learn.microsoft.com/en-us/dotnet/api/system.io.filestream)
- [Range HTTP Header](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Range)

### نکته
- هیچ وابستگی ناسازگار با .NET 9 استفاده نکنید.
- از کامنت‌های انسانی و سبک استفاده کنید.
- هیچ حافظه موقتی (Cache) استفاده نشود.
