## چالش عملکردی در پردازش داده

در این پروژه یک اپلیکیشن کنسولی با .NET 10 طراحی شده که داده‌های عددی را تولید و پردازش می‌کند. هدف، شناسایی و رفع گلوگاه عملکردی در ماژول پردازش داده (تشخیص اعداد اول) است.

### چالش:
- Performance Tuning: در متد ProcessData، پردازش اعداد اول با الگوریتم ناکارآمد انجام می‌شود و باعث کندی شدید اجرای برنامه روی داده‌های حجیم می‌گردد.

### راهنمایی (Hint):
- برای بهبود عملکرد، باید الگوریتم تشخیص اعداد اول و ساختار پردازش داده را بررسی کنید. بهینه‌سازی می‌تواند شامل تغییر حلقه‌ها، استفاده از توابع ریاضی مناسب یا الگوهای پردازش سریع‌تر باشد. به استفاده از ساختار داده‌ها و روش‌های LINQ نیز توجه کنید.

### نحوه اجرا:
- پروژه را با .NET 10 اجرا کنید. خروجی زمان پردازش برای حجم داده بزرگ نمایش داده می‌شود.

### وابستگی‌ها:
- فقط از پکیج‌های پایه‌ای .NET استفاده شده است و نیاز به نصب پکیج اضافی نیست.

### ساختار پروژه:
- فایل Solution (`DotnetPerformanceTuningConsoleApp.sln`)
- فایل پروژه (`DotnetPerformanceTuningConsoleApp.csproj`)
- فایل اجرایی (`Program.cs`)
