# Dotnet9ConsoleFileReadTroubleshooting

## چالش
در این پروژه یک برنامه کنسولی با .NET 9 طراحی شده که فایل‌های متنی یک پوشه را به صورت موازی می‌خواند و محتوای آن‌ها را تجمیع و نمایش می‌دهد. اما در اجرای فعلی برنامه، گاهی خروجی نادرست است یا با خطا مواجه می‌شود. وظیفه شما شناسایی و رفع مشکل فنی در مدیریت منابع و همزمانی (Concurrency) است.

## راهنمای شروع
1. پروژه را build و اجرا کنید.
2. خروجی را بررسی کنید و در صورت مواجهه با خطا یا خروجی غیرمنتظره، کد را تحلیل نمایید.
3. مشکل را یافته و راه‌حل مناسب برای مدیریت صحیح منابع و تضمین درستی خروجی پیاده‌سازی کنید.

## نکات
- از حافظه‌ی موقت یا کش‌شده استفاده نشده است.
- از هیچ پکیج NuGet اضافی استفاده نشده و پروژه فقط به پکیج‌های پایه .NET 9 وابسته است.
- برای بررسی مشکل، به نحوه دسترسی همزمان به منابع اشتراکی توجه کنید.
- پس از رفع مشکل، انتظار می‌رود خروجی برنامه همیشه صحیح و بدون خطا باشد.
