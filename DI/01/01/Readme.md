# Dotnet9ConsoleDiChallenge

## چالش
در این پروژه یک اپلیکیشن کنسولی با .NET 9 ایجاد شده که از Dependency Injection استفاده می‌کند. در پیکربندی DI، چندین پیاده‌سازی برای یک اینترفیس ثبت شده است. برنامه هنگام اجرا به‌جای اجرای صحیح، با خطا مواجه می‌شود یا خروجی غیرمنتظره دارد. وظیفه شما این است که مشکل موجود در پیکربندی DI را پیدا و برطرف کنید تا برنامه خروجی صحیح تولید کند.

## راهنمای شروع
- پروژه را build و اجرا کنید.
- پیام خطا یا رفتار خروجی را بررسی کنید.
- پیکربندی DI را به‌دقت بررسی کنید و با توجه به نیاز برنامه، آن را اصلاح نمایید.
- از هیچ حافظه موقتی یا کش استفاده نکنید.

## نکته
- در صورتی که چندین پیاده‌سازی برای یک اینترفیس ثبت شود، رفتار Resolve کردن DI را بررسی کنید.
- اطمینان حاصل کنید فقط یک پیاده‌سازی مناسب برای اینترفیس مربوطه ثبت شده است یا نحوه Resolve کردن آن با نیاز برنامه سازگار است.

## وابستگی‌ها
- .NET 9 SDK
- Microsoft.Extensions.Hosting
- Microsoft.Extensions.DependencyInjection
