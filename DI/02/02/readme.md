# چالش Dependency Injection در Console App با .NET 10

## شرح مسأله
در این پروژه یک برنامه Console App با .NET 10 پیاده‌سازی شده است که از ساختار Dependency Injection استفاده می‌کند. در پیاده‌سازی فعلی، نحوه ثبت سرویس‌ها در DI باعث بروز رفتار نادرست شده است. وظیفه شما تحلیل ساختار فعلی، شناسایی ایراد و اصلاح نحوه ثبت و مصرف سرویس‌ها است تا رفتار برنامه به صورت صحیح اجرا گردد.

## چالش
- Dependency Injection

## راهنمایی (Hint)
در پروژه‌های مبتنی بر DI هنگام ثبت چندین پیاده‌سازی برای یک اینترفیس، باید به نحوه resolve شدن سرویس‌ها و تأثیر ترتیب یا نوع ثبت دقت کنید. بررسی کنید که کدام پیاده‌سازی به صورت پیش‌فرض resolve می‌شود و این موضوع چگونه بر رفتار برنامه تأثیر می‌گذارد. همچنین مطمئن شوید که سرویس مورد نیاز کلاس مصرف‌کننده به درستی و بدون ambiguity تزریق می‌شود.

## مستندات اولیه برای شروع کار
- پروژه با .NET 10 و ساختار SDK-style ایجاد شده است.
- برای مدیریت DI از پکیج Microsoft.Extensions.DependencyInjection استفاده شده است.
- جهت build و اجرا کافیست دستورهای زیر را اجرا کنید:

bash
cd Dotnet10ConsoleDiChallenge
 dotnet build
 dotnet run


- در صورت اجرای صحیح، خروجی باید فقط در Console نمایش داده شود و فایل output.txt نباید تولید شود.
