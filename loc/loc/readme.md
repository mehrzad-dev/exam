پیاده‌سازی Localization چندزبانه در Console App با .NET 10
شاخص‌های کلیدی
- مدیریت Culture (en-US و fa-IR) برای نمایش صحیح تاریخ، اعداد و ارز
- نمایش پیام‌ها و برچسب‌ها بر اساس فایل‌های resource
- مدیریت جهت متن (RTL برای فارسی و LTR برای انگلیسی) در خروجی کنسول
- امکان توسعه آسان برای افزودن زبان‌های جدید
  راهنمای شروع
1. پروژه را Build و اجرا کنید.

2. زبان مورد نظر را وارد کنید (fa یا en).

3. ورودی و خروجی را بررسی نمایید که آیا قالب‌بندی تاریخ، عدد، ارز و متن با زبان انتخابی و جهت مناسب نمایش داده می‌شود یا خیر.

4. برای افزودن زبان جدید، کافی است فایل resx جدید با culture مناسب اضافه کنید.
   نکته
- برای مدیریت Localization از System.Resources و ResourceManager استفاده کنید.
- جهت متن RTL را می‌توانید با معکوس‌سازی رشته در خروجی شبیه‌سازی کنید.
- CultureInfo را بر اساس زبان انتخابی تنظیم نمایید تا DateTime و Number/Currency به‌درستی نمایش داده شوند.
