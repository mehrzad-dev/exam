# MemoryLeakDetectionInDotnet9

## چالش
در این پروژه یک اپلیکیشن کنسولی با .NET 9 طراحی شده است که هدف آن شناسایی و رفع مشکل Memory Leak در کد می‌باشد. پروژه هیچ سناریوی تجاری ندارد و صرفاً تمرکز بر مدیریت حافظه و جلوگیری از Memory Leak است. شما باید کد را بررسی کرده و مشکل Memory Leak را پیدا و برطرف نمایید.

## موارد مرتبط با hint
- توجه کنید که نگهداری مراجع غیرضروری به اشیاء بزرگ در حافظه می‌تواند باعث عدم جمع‌آوری آن‌ها توسط Garbage Collector شود.
- بررسی کنید که آیا داده‌ها یا اشیاء بزرگ به صورت غیرضروری در ساختارهای داده‌ای ذخیره می‌شوند یا خیر.
- بعد از رفع مشکل، باید مصرف حافظه به شکل قابل توجهی کاهش یابد و Memory Leak برطرف شود.

## مستندات اولیه برای شروع کار
- پروژه با .NET 9 ایجاد شده است و فقط به SDK اصلی نیاز دارد.
- هیچ پکیج NuGet اضافی نیاز نیست.
- برای اجرا، کافی است دستور `dotnet run` را در مسیر پروژه اجرا کنید.
