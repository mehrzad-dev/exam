# پروژه مدیریت خطا و Exception در پردازش داده‌های ورودی

## چالش
در این پروژه یک اپلیکیشن Console با .NET 9 پیاده‌سازی شده است که از کاربر یک لیست از اعداد صحیح را به صورت رشته‌ای (جداشده با کاما) دریافت و مجموع مقلوب (Reciprocal) آن‌ها را محاسبه و نمایش می‌دهد.

کد فعلی مدیریت مناسبی برای خطاهای احتمالی ندارد و در صورت ورود داده‌های نامعتبر یا شرایط خاص (مانند تقسیم بر صفر) برنامه با Exception متوقف می‌شود. هدف شما شناسایی و اصلاح این نواقص است تا برنامه در مواجهه با ورودی‌های نادرست یا خطاهای محاسباتی، به درستی پیام مناسب نمایش دهد و از Crash شدن جلوگیری کند.

## راهنمای شروع
- پروژه با .NET 9 و ساختار SDK-style آماده شده و بدون نیاز به فایل solution قابل build و اجرا است.
- کد را بررسی و نقاط ضعف مدیریت خطا را پیدا کنید.
- ورودی‌های مختلف (مانند مقدار خالی، داده غیرعددی، صفر و ...) را تست کنید.
- مدیریت خطا را به گونه‌ای پیاده‌سازی کنید که تجربه کاربری بهبود یابد و هیچ Exception بدون مدیریت نماند.

## نکات
- از حافظه‌ی موقت یا کش‌شده استفاده نکنید.
- فقط از پکیج‌های پایه‌ای .NET استفاده شده و نیاز به نصب پکیج اضافی نیست.
- فایل Program.cs شامل منطق اصلی و چالش است.
