# چالش امنیتی Minimal API در .NET 9

## شرح مسأله
در این پروژه یک Minimal API با .NET 9 پیاده‌سازی شده که ورودی کاربر را دریافت و در پاسخ بازمی‌گرداند. اما در پیاده‌سازی فعلی یک آسیب‌پذیری امنیتی مهم وجود دارد که می‌تواند زمینه‌ساز حملات Injection شود. وظیفه شما شناسایی و رفع این آسیب‌پذیری است.

## چالش
- شناسایی آسیب‌پذیری امنیتی موجود در مدیریت ورودی کاربر
- جلوگیری از حملات Injection با اصلاح منطق دریافت و بازگشت داده
- حفظ سادگی و عملکرد صحیح API

## راه‌اندازی پروژه
1. اطمینان حاصل کنید که .NET 9 SDK روی سیستم شما نصب است.
2. دستور زیر را برای اجرای پروژه وارد کنید:

   bash
   dotnet run
   

3. با ابزارهایی مانند curl یا Postman می‌توانید به مسیر `/echo` درخواست POST ارسال کنید.

## نکته
در بخش hint به راهنمایی کلی برای شناسایی و اصلاح آسیب‌پذیری توجه کنید.
